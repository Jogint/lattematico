# 🏰 Lattemático !!

## Descrição

**Lattemático** é um jogo de aventura educacional em que o jogador assume o papel de **Latte**, um jovem garoto genial que foi capturado por **Sr. Callus**, um cientista que deseja construir o robô mais inteligente do mundo. 

Seu dever é se provar que Callus, passando por todos os seus desafios e seus robôs de defesa para acabar com o histórico de alunos desaparecidos para serem parte de experimentos.

## Mecânicas do Jogo

- **Exploração de Andares:** Cada andar possui diferentes monstros criados por Sr. Callus. O jogador deve derrotá-los para progredir.
- **Porta Especial e Desafios:** A cada 5 níveis, há uma Porta Especial que só pode ser aberta ao completar um desafio matemático.
- **Progressão de Dificuldade:** Conforme avança, Latte enfrentará monstros mais poderosos e desafios mais complexos.

## Como jogar

O executável do jogo está presente na pasta "jogue-agora". Você só precisa fazer o download e se divertir enquanto aprende.
